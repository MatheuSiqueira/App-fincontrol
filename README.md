# App-fincontrol

App para controle de finanças baseado na metodologia 50/30/20:

- **50%** para necessidades (moradia, contas, alimentação, transporte, saúde)
- **30%** para desejos (lazer, restaurantes, assinaturas, compras)
- **20%** para poupança/dívidas (investimentos, reserva de emergência, quitação de dívidas)

## Funcionalidades

- Definição da renda líquida mensal
- Cálculo automático do orçamento ideal de cada categoria
- Registro de gastos categorizados
- Dashboard com barras de progresso e gráficos (pizza e comparativo orçado x gasto)
- Dados salvos localmente no navegador (localStorage), sem necessidade de backend

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```
